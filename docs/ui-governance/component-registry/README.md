# GNI UI Component Registry

The authoritative index is [`registry.yaml`](registry.yaml). Each reusable
component has one permanent detailed record in [`components/`](components/).

A component is not generally approved until it has a permanent identifier,
complete record, owner and backup owner, documented devices/states/preferences,
central index entry, and required review. Existing components are initially
Draft or Experimental and are reviewed when materially modified or included in
a major release.

Registry changes are required when contracts, variants, devices, lazy loading,
preferences, ownership, limitations, deprecation, replacement, decisions, or
exceptions change.
